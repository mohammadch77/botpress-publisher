Publish WordPress posts to Telegram and Bale channels via Bot.

== Description ==

BotPress Publisher lets you manage Telegram and Bale bot channels directly from
WordPress, queue posts for publishing, and control everything from a modern
Vue-based admin dashboard.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/botpress-publisher` directory.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use the BotPress menu item to configure channels and bot settings.
